# OathBridge

Fault-tolerant, high-performance OathBridge enables secure, asynchronous communication between decentralized peers, managed by a robust service.

OathBridge is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Fault-tolerant, high-performance OathBridge enables secure,
- asynchronous communication between decentralized peers,
- managed by a robust service

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/OathBridge.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

OathBridge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
